# Portfolio — Marc Blouet

Portfolio perso : qui je suis, ce que j’utilise, les projets en cours.

Site : [marcblouet.com](https://marcblouet.com)

## Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- daisyUI
- Vercel
- Brevo

## Contenu

- Hero + photo
- À propos
- Stack
- Projets (Portfolio, CaristePrêt, Snippix)
- Contact (formulaire + GitHub / X)
- Switch clair / sombre

## Lancer en local

```bash
npm install
npm run dev
```

Ouvre [http://localhost:3000](http://localhost:3000).

## Thèmes

daisyUI `winter` (clair) et `night` (sombre).
Winter par défaut, night si le système est en sombre.
Le bouton soleil / lune bascule le thème.
